# Living Blueprint — Signature Direction

## Concepts proposed

1. **Living Blueprint** — Animated technical-drawing layer (SVG stroke draw, dimension callouts, parallax grid). *Rationale: most “authored engineering” without consumer gimmick.*
2. **Precision Machine** — Exploded CAD assemble-on-entry. *Rationale: strong craft signal; risk of feeling demo-reel if overused.*
3. **Molten Metal / Copper** — Liquid sheen + ember particles. *Rationale: memorable materiality; easier to tip into decorative/luxury-goods territory.*

## Decision

**Committed: Living Blueprint.**

## Demo surfaces shipped

- `HeroBlueprint` — WebGL wireframe assembly (lazy Three.js), SVG self-draw overlays, split-text mechanical reveal, metric count-up, magnetic CTAs, parallax grid, custom crosshair cursor
- `ProcessBlueprint` — scroll-linked copper path draw + dimension markers (homepage scroll hero-moment)
- Site chrome — Lenis smooth scroll + blueprint cursor (fine pointer only; reduced-motion safe)
