# Artistic Engineers

Modern industrial website redesign for [Artistic Engineers](https://www.artisticengineers.in) — precision metal engineering and smart space systems.

## Stack

React · TypeScript · Vite · Tailwind CSS · Framer Motion · Lucide · React Hook Form · Zod · TanStack Query

## Develop

```bash
npm install
npm run dev
```

- Design system gallery: `/design-system`
- Contact / quote form: `/contact`
- Planning docs: `docs/`
